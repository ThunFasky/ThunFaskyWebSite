# music/

サイトの「作曲したもの」にある音楽プレイヤー（ThunDecky の Web 版 / `js/thundecky.js`）で流す曲を置くフォルダ。

- MP3 などの音声ファイルをこのフォルダに入れるだけで、ファイル名順に並んで再生できるようになる
  （GitHub の API でフォルダの中身を読んでいる）。曲名はファイル名から拡張子を除いたもの
- ジャケットは MP3 に埋め込んだ画像（ID3 の APIC）を使う。無ければ NO IMAGE
- 曲順や曲名、ジャケットを指定したいときは `tracks.json` を置く。あればこちらが優先される

```json
[
  "01 曲名.mp3",
  { "src": "music/02 別の曲.mp3", "title": "表示したい曲名", "art": "music/02 ジャケット.jpg" }
]
```

対応形式は mp3 / m4a / aac / ogg / opus / wav / flac / webm（再生できるかはブラウザによる。MP3 が確実）。
